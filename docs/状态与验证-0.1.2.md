## 验证边界

本机 macOS arm64、Qt 6.11.2、AppleClang 17、CMake 4.4.3。执行：

```sh
cmake -S . -B build/vscode -DPAT_BUILD_TESTS=OFF
cmake --build build/vscode --target pat_app --parallel 4
BUILD_DIR=build/merge-axis-check TEST=1 RUN=0 ./scripts/build_and_run.sh
RUN=0 ./scripts/build_and_run.sh
```

结果：以上配置及构建成功；三组回归全部通过（22.30 秒），core 25 通过/2 可选跳过、serial 5 通过、UI 32 通过。两个跳过仍为可选旧样本与未启用的压力测试。VS Code 设置 JSON、编译数据库中的 C++20/Qt 功能宏检查通过（37 个编译条目），Shell 语法及差异空白检查通过。常用应用包两项 Bundle 版本均为 0.1.2。

Windows PowerShell / MSVC / MinGW 未在本机实跑；本节点不声称已通过 Windows 构建或发布验收。Windows 推荐先指定 Qt 套件验证：
