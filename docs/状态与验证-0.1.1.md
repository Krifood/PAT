# 0.1.1 当前状态与验证

日期：2026-10-24（Asia/Shanghai）。状态：开发构建，非正式发布；不创建发布标签。软件版本由 CMake 统一提供给帮助页和 macOS 应用包。

## 本次提交范围

这是当前工作区的整合提交，除本次修复外，还包含此前未提交的导入与图表改进：

- VMC 后台只读扫描、确认页、时间戳单位选择；macOS/Windows 优先使用系统文件选择能力。
- 修复扫描和转换正常收尾时 `QProgressDialog::close()` 触发 canceled，从而把真实失败误报为取消的问题；用户主动取消仍有效。
- 支持已知消息在时间戳末尾中断、长度为 FF 且后续全部 FF 的末尾残帧，拒绝中途非 FF 数据、未知消息残帧及一般截断。
- 转换前显示残帧丢弃数量、原文件偏移和字节数；结果提示及来源段 JSON 保留信息，不修改原始日志、不补造末条数据。
- 信号短名称与分组标题分离，子图标题左上对齐，空间坐标分组/关键字筛选。
- 光标亮黄色数据标签、底板与重叠避让，紧凑图例及等距留白；保留多子图抗锯齿。
- 辅助线悬停提示不再超时，光标标签简写为 k:/v:。
- 时序/二维/三维共用离线区间栏：端点拖动、整体平移、精确输入、翻段及全范围复原；混合日志按窗口回读。
- 构建启动脚本与应用包标识改进；保留工作区已有的 `samples/ha_log` 忽略规则，不提交实际日志或构建产物。

schema 1/2/3、PATMBIN1 和协议字段解析规则不变。新增来源段可选字段：`discarded_tail_records`、`discarded_tail_bytes`、`discarded_tail_offset`。字节数包括残帧头及其后填充，偏移从源文件起点计；这些字节不重复计入普通 FF 填充或完整记录。

### 同日后续：差值空图与异步时间配对

单位不同会阻止创建关系图；另一类空图来自混合日志两个流没有完全相同的原始时间戳。新建关系图默认以 A 为基准线性插值 B，并提供严格模式，不修改已有定义。普通数据与索引混合日志均支持插值；混合日志先配对/插值再抽稀，时间差先按 uint64 计算，窗口读取保留 B 的邻接块。不外推、不跨来源段、不越过非有限 B 样本；有效样本之间未设置最大插值间隔，状态量或长时间缺采应使用严格模式。图内增加空数据说明，单有效点显示点标记。

## 已知限制

- FF 尾部恢复只适用于上述明确特征，不做通用文件修复；末尾丢失的时间戳/负载无法还原。
- 原始时间戳单位仍需用户按设备来源确认；空间时间区间栏只在离线模式启用。
- 本轮 UI 自动测试使用 offscreen 平台；Windows 原生文件窗口、目标机器性能与真实串口长时采集未在本轮验收。
- 正式签名、公证、目标机器发布验证仍待完成；不把本机回归通过视为正式发布。

新版本机应用：`build/local/pat_app.app`。退出已运行的旧进程后再打开，避免继续使用内存中的旧版本。
