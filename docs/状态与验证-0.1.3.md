# 0.1.3 功能基线

日期：2026-10-26（Asia/Shanghai）。分支：`feature/pat`。基线父节点：`8585b34`。
检查点标签：`checkpoint/0.1.3-20261026`（annotated tag）。此为首版 UI/易用性调试前的开发检查点，不是正式发布或 Windows 验收版本。

## 已保存功能与最终交互

- 二维轨迹可开启“等比例坐标”，每单位 X/Y 对应相同像素长度；窗口变化后保持比例。右键可还原视图和放大/返回多子图。
- 当前时间区间极值使用已加载数据，显示变换后、前端绘图抽稀前计算，忽略无效值；时序图以小字号 `max:` / `min:` 两行显示，隐藏信号不参与。纵向缩放不裁切统计区间。
- 游标数据默认跟随；右键“打散数据块”后才可独立拖动。极值块和合并子图数据源框默认可拖动；“还原信息块位置”恢复布局与游标跟随。位置仅当前子图会话内保存，不写入数据文件。
- 数据线宽：室内 1.0、户外 1.2；辅助线主线 1.0、描边 2.0、统一明黄色，命中区仍为 6 像素。未改变采样值或引入数据平滑。
- 辅助线可右键输入 X/Y（支持科学计数法）、编辑、删除；垂线同步时序子图。时序和二维鼠标位置显示当前轴坐标；三维显示屏幕位置和命中投影点的 XYZ，不伪造未命中位置的深度。
- 子图边距和分隔条收紧；全视口合并调度重绘及游标离开清理，防止多子图游标残影，手工辅助线不受影响。
