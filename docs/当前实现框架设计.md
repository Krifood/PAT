# PAT 当前实现框架设计

## 总览
当前实现采用“核心解析 + Qt UI 展示”的分层结构，核心仅负责格式解析与数据解析，界面层负责交互、分组与图表展示。

- 核心层（`src/core`）
  - `FormatDefinition`：格式字段定义与 JSON 解析
  - `FormatDocument`：格式文件加载/保存与文本管理
  - `RecordParser`：二进制数据解析
  - `DataSession`：数据加载与统计信息（min/max/时间跨度）
- 界面层（`src/ui`）
  - `MainWindow`：入口与模块编排
  - `SignalTreeWidget`：信号树 UI 与拖拽 MIME
  - `SignalTreeController`：信号树构建与选中状态管理
  - `DisplayGroupManager`：信号分组与合并规则
  - `ChartArea`：图表区域容器与共享时间轴
  - `SignalChartView`：单图表交互（缩放、平移、框选、游标、拖拽合并）
  - `FormatEditorDialog`：格式编辑与验证对话框

## 子系统关系
- 核心子系统（解析）
  - `FormatDocument` 维护格式文本与 `FormatDefinition`。
  - `RecordParser` 按 `FormatDefinition` 解析数据文件，统一时间轴单位。
  - `DataSession` 管理解析结果与统计信息，向 UI 提供 `Series` 与 `SeriesStatistics`。
- UI 子系统（展示）
  - `SignalTreeWidget` 只负责树形显示与拖拽 MIME。
  - `SignalTreeController` 负责树构建与勾选状态，输出需要展示的信号集合。
  - `DisplayGroupManager` 将“勾选信号 + 合并规则”转为展示分组。
  - `ChartArea` 管理子画布列表、共享时间轴与游标同步。
  - `SignalChartView` 负责单图交互（缩放、平移、框选、右键菜单、拖拽合并）。

## 数据流与控制流
1. 格式加载
   - `MainWindow` 调用 `FormatDocument::LoadFromFile` 得到 `FormatDefinition`。
   - `SignalTreeController::Build` 根据 `group` 与 `groups.path` 构建树形结构。
2. 数据加载
   - `MainWindow` 使用 `DataSession::Load` 解析数据，生成 `Series` 与统计信息。
3. 展示更新
   - `DisplayGroupManager::UpdateGroups` 将“信号勾选 + 合并规则”转化为展示分组。
   - `ChartArea::BuildCharts` 按组创建 `SignalChartView`，并应用共享时间轴。
4. 交互同步
   - `SignalChartView` 发出缩放/平移/框选请求，`ChartArea` 计算并应用新的 X 轴范围。
   - 游标移动由 `SignalChartView` 触发，`ChartArea` 统一更新所有子图游标。
   - 拖拽合并由 `SignalChartView` 触发，`MainWindow` 调用 `DisplayGroupManager` 更新分组。

## 关键设计点
- 分层与内聚
  - 解析逻辑全部位于 `core`，界面层不直接操作解析细节。
  - 合并规则独立在 `DisplayGroupManager`，避免 UI 与数据耦合。
- 共享时间轴
  - `ChartArea` 负责统一 X 轴范围与游标同步。
  - `FormatDefinition.timeAxisUnit` 作为统一时间单位，解析阶段完成换算。
- 大数据展示
  - `ChartArea` 对数据进行抽稀显示（可配置最大显示点数）。
- 分组展示
  - 通过 `group` 路径与可选 `groups` 描述，实现分组树与多列展示。

## 目录与文件分布
- 核心：`src/core/FormatDefinition.*`、`src/core/FormatDocument.*`、`src/core/RecordParser.*`、`src/core/DataSession.*`
- 界面：`src/ui/MainWindow.*`、`src/ui/SignalTreeWidget.*`、`src/ui/SignalTreeController.*`、`src/ui/DisplayGroupManager.*`、`src/ui/ChartArea.*`、`src/ui/SignalChartView.*`、`src/ui/FormatEditorDialog.*`

## 可扩展点（后续改进参考）
- 多数据集/多格式并行解析与展示
- 异常检测规则（阈值/区间/离群点）
- 解析进度与异步加载（大文件 UI 不阻塞）
- 统计面板（每信号 min/max/均值等）
- 时间轴单位自动换算与显示策略

## 2026-09-17 串口分析扩展

开发分支在原有离线模块之外增加以下组件，实施状态与验收条件见[技术变更路线](技术变更路线.md)：

- `src/core/RecordDecoder`：由旧文件解析器抽出的单帧字段解码，支持大小端、8/16/32 位整数及 32/64 位浮点；无符号整数字段可按 `bit_offset`、`bit_width` 提取位段。`RecordParser` 复用它进行分块文件读取。
- `src/core/VmcLogReader`：流式读取 VMC 的 84 字节全局头、A5 描述项、5A 数据帧与 FF 尾填充，校验描述负载长度并保留未知控制字节、元数据和源序号。
- `src/core/UnifiedLogWriter`：把一个或多个 VMC 来源按流写入 `.patbin`，单块目标 1 MiB、总写缓冲默认 32 MiB，并生成 CRC、尾索引及 schema 3 JSON；界面在 Qt Concurrent 工作线程调用，可请求取消。
- `src/core/IndexedMixedReader` 与 `MixedDataSession`：验证 JSON/BIN 结构指纹和索引，只读取当前请求字段所在的数据块，以默认 128 MiB 预算保留最小值/最大值概览。多来源段使用相对横轴和断点，原始时间戳不改写。
- `src/core/SerialFrameAssembler`：在任意字节块边界上搜索固定帧头与总帧长，输出完整帧并统计跳过字节；可按模板验证 `sum8` 累加和。未配置校验的模板仍无法排除误碰帧头。
- `src/core/InputReader` 与 `FrameExporter`：离线二进制或十六进制文本输入，以及原始帧 TXT/CSV 导出和归类。
- `src/core/CaptureSession`：在分帧前记录原始字节，解码后记录带 UTC 时间戳的 CSV；`LiveDataSession` 仅保留有界绘图窗口。
- `src/serial/SerialCaptureWorker`：在工作线程中使用 Qt Serial Port，按批次向主界面发送样本与状态。`MainWindow` 增加串口控制面板；`ChartArea` 对实时数据增量刷新、按采样序号显示横轴。

构建目标为 `pat_core`、可选 `pat_serial` 和可选 `pat_app`。`PAT_BUILD_GUI=OFF` 时无需 Widgets/Charts；`PAT_ENABLE_SERIAL=OFF` 时无需 SerialPort。旧格式无 `schema_version` 或 `framing` 时继续按固定记录解析；串口新模板使用 `schema_version: 2`。

## 2026-09-22 多组二维/三维空间图扩展

`TrajectoryData` 提供二维与三维采样配对：离线按记录顺序，实时按成功帧采样序号，过滤非有限值；抽稀分别保留 X/Y 或 X/Y/Z 极值、首点和末点。`TrajectoryView` 是空间图管理器，默认创建一组二维 `TrajectoryPlotWidget`，并可动态新增二维/三维子图。二维使用 Qt Charts，三维使用 QWidget/QPainter 轻量旋转投影。同维度子图通过标题拖拽合并，目标子图保存多条轨迹及各自坐标配置；跨维度合并被拒绝。

实时源序列仍是有界缓存，空间子图在每次数据通知时按采样序号增量复制新坐标点，因此暂停显示、切换页签或源缓存滚动不会删除子图历史。每条轨迹完整历史保存在子图模型，绘制时最多提交 4,000 个点；开始新会话、删除子图或修改该轨迹坐标时清理相应历史。该结构以随会话增长的空间历史内存换取完整轨迹，长期运行需要目标机验收。坐标转换和离线地图包边界见 [DESIGN 第 11 章](DESIGN.md)。

## 2026-09-21 显示处理扩展

`SeriesProcessing` 保存不进入协议模板的显示变换和差/和派生定义。原始信号由 `ChartArea` 在抽稀后应用比例与平移，`TrajectoryView` 在空间历史渲染时应用同一变换；复原属性无需重建历史。差值和和值序列离线按相同横轴配对，实时按样本批次增量生成，标题记录运算和两个来源。`SignalChartView` 接收逻辑信号 ID、源序列指针和显示变换，使曲线、光标及辅助线使用同一显示值，同时保留组合、打散、隐藏和拖拽结构。详细数据边界见 [DESIGN 第 12 章](DESIGN.md)。

### 信号检索区

`MainWindow` 在主信号树下维护独立的 `SignalTreeWidget` 搜索结果区。输入被拆成多个不区分大小写的关键词，并与信号名、说明、分组和单位匹配；结果项只保存原信号索引。结果勾选状态与主树双向同步，并复用拖拽 MIME 和信号右键操作，因此可直接显示/隐藏、合并、设置属性或创建差/和关系图。搜索条件变化只重建结果项，不修改曲线和属性状态。

### 显示主题

`AppTheme` 集中保存窗口控件、画布、坐标轴、网格、交互线和曲线色板。`MainWindow` 从 `QSettings` 读取主题并生成全局控件样式；`ChartArea` 将同一主题传给每个 `SignalChartView`，`TrajectoryView` 同步更新所有二维/三维子图。主题切换只更新图形对象，解析会话、原始样本、派生缓存、空间历史和串口工作线程保持原状态。主题适用边界见 [DESIGN 第 13 章](DESIGN.md)。
