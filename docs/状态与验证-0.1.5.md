- 辅助线框使用主题普通文字、差异背景与虚线边框；游标保留原样式，确保两类数据容易区分。避让只重排已计算文本，不在每次鼠标移动时重新计算交点。
- 时间范围条从 50px 压缩至 38px；0–100% 参考尺、选择范围和鼠标联动保持不变。

## 2026-11-18 后续补充：辅助线交点读数常驻

- 添加辅助线后，画布内常驻显示对应交点汇总，鼠标离开不清除，可直接截图。数据块随辅助线位置、显示区间、数据和主题更新，辅助线离开可视范围时隐藏，删除辅助线时一并删除。
- 右键勾选“防拥（隐藏辅助线交点数据）”，暂时隐藏本子图所有辅助线读数及其悬停浮窗；取消勾选恢复显示。辅助线本身、普通数据游标及“复制本线全部交点”不受影响。
- 防拥状态按子图当前会话保存，相同信号组合重绘保留；新的子图默认显示。不修改原始数据或格式文件。
- 每线一个汇总块，长名称省略、最多显示 12 个交点（小画布更少），超量会注明数量，完整内容可右键复制。多块优先错开摆放，过密时使用防拥开关；不是将全部交点强行铺满画布。
- 横线标注“几何交点”，纵线标注“最近采样”，不改变原有计算语义。
- 验证：鼠标离开后常驻读数保留、右键防拥开关/恢复、辅助线保留、悬停读数抑制与删除清理通过；逐像素游标残影回归仍通过。macOS 完整 core / serial / UI 三组通过（25.99 秒），应用重新编译完成。Windows 未实跑。

## 后续补充：中键平移与网格风格

- 在绘图区按住鼠标中键拖动。时序图水平拖动联动其他时序子图及时间范围控件，仍受数据范围限制；竖向平移本图，右键“还原纵轴自动范围”清除偏移。整个时间域已显示时，水平拖动受边界约束，可先缩小显示区间。
- 二维（含地理）平移 X/Y 显示范围，不修改信号值；拖动后自动范围关闭，右键“还原视图”复位。测距开启时仍支持中键平移，不新增或移动测距锚点。等比例模式保持轴跨度比。
- 三维中键平移投影视图，不改变三维数据；左键旋转、滚轮缩放保留，双击还原。
- 根据反馈，时序/二维改为右键“密集纵轴刻度”：增加带数值的 Y 轴主刻度，以及与刻度一一对应的水平参考线。不增加横轴密度，不绘制无标签次网格。按绘图区高度及字体高度自适应，间隔至少约 40px（极矮子图保留原数量），最多 10 个刻度；放大/缩小子图后更新密度，取消勾选恢复原数量。刻度读数继续使用原有缩放/偏移说明，不改变原始数据。
- 三维保留“密集网格”归一化参考面，不表示各轴单位相等；自动参考线均不影响手动辅助线。
- 风格按子图当前会话保存；同一时序信号组合重绘时保留，创建新图/合并成新组合默认普通风格。不写入源文件或格式 JSON。
- 验证：新增中键平移、轴跨度不变、纵轴复位、网格开关、主题切换及手动辅助线保留回归；macOS 完整 core / serial / UI 三组测试通过（25.67 秒），日常应用构建通过。Windows 未实跑。

## 2026-11-15 后续补充：同步字故障跳过

- 原数据区扫描在预计帧起点不是 `0x5A` 时直接终止；现扫描后续可靠帧并继续，扫描/转换共用同一恢复逻辑。故障偏移、实际同步字、跳过字节数及恢复结果写入输出 JSON 的 `source_segments[].parse_fault_report`，沿用转换提示弹窗。
- 恢复须确认已知消息、正确描述长度、完整负载，且后面接另一完整帧或可验证的文件尾；不能确认则报告剩余字节未转换，不将垃圾数据伪装成记录。扫描期间支持取消，不修改源文件。
- 此补充不放宽描述表、首帧定位、FF 尾部校验或合法同步字下的不完整帧检查；也不保证检测到此前已读帧内部的负载损坏。
- 回归覆盖损坏帧头、插入字节/伪同步字、丢字节、不可恢复短尾、跨 64 KiB 扫描边界、转换报告与取消操作。
