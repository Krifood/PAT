# PAT 串口分析功能使用说明

> 开发分支试运行说明。当前 CMake 项目版本为 0.1.1 开发构建；首个集成发布需完成真实设备和目标机器验收。

## 构建与验证

在 PAT 源码目录执行以下命令。`build_and_run.sh` 默认仅编译并启动应用，不运行测试；只编译时设置 `RUN=0`，需要编译并验证时设置 `TEST=1 RUN=0`。显式开启的测试失败仍会停止脚本。

```sh
./scripts/build_and_run.sh
RUN=0 ./scripts/build_and_run.sh
```

macOS 构建结果是 `build/local/pat_app.app`；不要运行历史构建遗留的 `build/pat_app` 裸程序。如需把 Qt 运行库一同打包，执行 `PACKAGE=1 RUN=0 ./scripts/build_and_run.sh`，结果在 `build/local/stage/pat_app.app`；交付前建议增加 `TEST=1` 做回归。脚本会自动查找 Homebrew 的 Qt；使用 Qt 官方安装包时设置 `QT_ROOT=/path/to/Qt/6.x/macos`。需预装 CMake、C++20 编译器以及 Qt 6 的 Core、Widgets、Charts、Concurrent、SerialPort 模块；仅在 `TEST=1` 时需要 Qt Test。

手工构建和运行测试：

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6 -DPAT_BUILD_GUI=ON -DPAT_ENABLE_SERIAL=ON
cmake --build build -j 4
ctest --test-dir build --output-on-failure
```

运行时使用 Qt Widgets 桌面界面；macOS 可执行 `cmake --install build --prefix build/stage` 得到附带 Qt 运行库的 `pat_app.app`。构建时若不需要串口，可设置 `-DPAT_ENABLE_SERIAL=OFF`；仅构建解析核心可再设置 `-DPAT_BUILD_GUI=OFF`。

## 离线试用

1. 在 PAT 中选择“文件 → 打开格式”，打开 `samples/serial_sensor.json`；也可选“新建串口模板”编辑自己的 JSON。
2. 选择“预览帧解码”，输入 `AA 55 90 01`，应得到温度 `0 °C`。
3. 选择“打开数据”，打开 `samples/serial_sensor.hex`，在左侧勾选温度信号；曲线横轴为成功解析帧的采样序号，示例包含两帧。
4. 选择“导出原始帧”，输入选同一 `.hex` 文件，输出选 `.txt` 或 `.csv`；可按模板、完整帧、指定字节或解析字段归类。导出文件只含一行表头和逐帧数据行。

二进制原始流和 `.bin` 日志也可直接打开。扩展名 `.txt`、`.log`、`.hex`、`.csv` 按十六进制文本读取；其它扩展名按原始字节读取。文本中仅识别完整十六进制词，如 `AA`、`AA5501`、`0xAA`，其它词跳过；单个无分隔符片段上限为 64 MiB。时间戳或地址若与有效十六进制词形相同，仍可能被识别为数据，导入前应检查源文本。

## 信号做差与差值趋势

加载数据后，点击左侧“信号做差 / 差值趋势...”或“分析”菜单下同名入口，无需预先勾选两条信号。在 A、B 各自的搜索框输入信号名、分组或单位，再从下拉列表选择信号，点击“创建趋势图”。默认计算 **A − B**，“交换 A / B”可反转相减顺序；也可切换为和值。右键信号同样可以打开此窗口。

结果自动显示在“时序曲线”页的独立子图中，标题标明运算和来源；可重复创建不同信号对的趋势图，复用时间区间、缩放、光标和辅助线功能。图内右键“取消显示本图信号”可移除关系图。

计算使用原始解析值，不含信号显示比例与平移；两条信号须单位相同。新建图默认选择“共同时间轴·前值保持”：仅在临时运算图合并 A/B 的时间点，不降低时间精度；任一信号更新时，另一信号沿用最近一次值，生成阶梯式差值或和值。仅在两信号共同覆盖的时间内有效，不跨来源段、不越过非有限值，但段内长时间没有更新仍会保持旧值，需结合采样状态判断。不同时间单位应先正确配置统一，不能靠前值保持补救错误单位或时钟偏移。原始日志、模板和原始信号图不变。

也可选择“按 A 时间线性插值 B”：在 A 的每个采样时间，利用 B 前后两个有效样本估算 B，再计算差值，适合异步连续信号。仅在 B 的有效时间范围内插值，不外推、不跨日志段；不会越过非有限值样本，但有效样本之间即使时间间隔较大也会插值，需结合采样间隔判断是否适用。图标题标明所选模式。在线性插值模式交换 A/B 会改变采样时间基准；前值保持则保留共同时间轴。

对状态量、开关量或需要严格对时的分析，选择“严格同时间（不插值）”（普通数据沿用数值容差）。不同消息流时间戳完全不重合时，严格模式可能没有有效差值；可删除旧关系图后用线性插值模式重建。两信号没有共同时间范围时仍无有效差值，图内会提示；只有一个有效点时显示点标记。

## 绘图缩放、对齐与显示控制

- 时序图默认在数据上下各留约 8% 范围；滚轮缩放时间轴，Ctrl + 滚轮缩放当前图纵轴，也可右键选择纵向放大/缩小和恢复自动范围。纵向缩放在数据刷新时保留，重新组合或重建子图后恢复自动范围。
- 时序子图使用统一的左右绘图区边界；不同单位不强行共用纵轴数值范围，但相同时间点在各图中横向对齐。
- 双击时序图切换单图放大/返回多图；二维/三维子图双击标题切换。隐藏的图和数据仍保留，修改图组合后返回多图。
- 窗口标题和图表顶部显示当前格式、数据文件名，悬停顶部信息可查看完整路径；实时模式显示“实时采集”。
- 时序垂向辅助线的添加、拖动、删除同步到所有时序子图；横向辅助线保持各图独立。清除某图辅助线时，同时移除共享垂线，其他图的横线保留。
- 游标数值固定在绘图区上方排列，保留亮黄色字和不透明深色底板，多信号自动错开，不再随曲线高度上下跳动。
- 二维/三维每条轨迹可勾选“显示”，子图标题栏支持全部显示/隐藏。隐藏不会清空轨迹历史、信号选择或停止采集；隐藏轨迹不参与自动范围计算。删除使用紧凑关闭图标，悬停显示用途；临时屏蔽请用勾选而非删除。
- 二维轨迹开启抗锯齿，时序与二维曲线使用圆角连接。不会对原始值做平滑：前值保持的阶梯、真实突变和概览抽稀保留；观察细节请缩小时间区间。

## 串口采集

1. 加载含 `framing` 的模板；从“视图 → 串口采集”打开连接面板，刷新并选择端口，设置波特率、数据位、校验、停止位、流控、无数据告警时间和日志目录。面板默认收起，需要时可再次从“视图”菜单打开或关闭。
2. 在信号树中勾选要显示的字段，画布立即显示对应的空绘图区。点击“开始采集”会自动打开并配置所选串口；首次采集若未勾选信号，会自动勾选前四项。收到有效帧后才会绘制曲线，最近 100 帧显示在采集面板。
3. “暂停显示”只暂停图表刷新，串口读取、解码和两类日志继续；“跟随最新采样”可关闭以检查当前缓存内的历史。点击“停止采集”会关闭串口，之后可再次连接。

画布底部的“已收到字节／已解析帧／跳过字节”统计在暂停显示时仍继续更新。“暂停显示”不会冻结采集和解码。光标交点标签将 `k:` 与 `v:` 分两行显示；多幅子图仅最下方显示横轴刻度，不重复显示横轴标题。时序纵轴与二维轨迹坐标使用紧凑刻度，大数自动使用科学计数法；大基数、小变化时使用 `Δ` 差值刻度，标题区附原值换算说明（悬停查看完整说明），原始数据和光标读数不变。

拖动时序子图标题到另一个子图的标题或绘图区，会合并两图的全部信号；按住 Shift 拖动标题可调整顺序。也可选择多组或多条信号后拖到目标信号上，已有组合会整体参与合并，不会只保留最后两条。取消勾选一条信号时，其余信号保持组合；组合图可在图内右键选择“打散组合画布”，拆回各自的子画布，并保留勾选状态。

辅助线可从子图的横轴区域拖出横线、从纵轴区域拖出竖线，也可在图内右键添加。拖动线本身可调整位置；在线上悬停时显示该子图各信号与辅助线的交点值，同时保留红色共享光标。横线与同一信号有多个交点时，悬停提示显示当前可见范围内前 40 个交点及剩余数量；在线上右键可复制全部可见交点或删除辅助线，图内右键也可清除本图全部辅助线。

左侧“信号检索与快捷操作”可按信号名、说明、分组或单位筛选，搜索结果可直接勾选、拖拽及执行右键操作，清空搜索不会隐藏已选信号。右键信号打开“信号属性”，计算规则为“解析值 × 显示比例/LSB 系数 + 整体纵向平移量”；组合图可在图内分别设置单线。该设置同步改变时序曲线和二维/三维空间坐标的显示，不修改协议模板、解析日志或派生图源值，并可通过“复原信号显示”恢复。选择两个同单位信号后可创建 `A-B` 差值或 `A+B` 和值关系图；标题声明两个数据来源，关系图不出现在信号树中。实时采集和暂停显示期间都会继续维护派生数据，图内“取消显示本图信号”可删除关系图。

“二维/三维轨迹”页默认保留一组二维图，可动态新增二维或三维子图。每个子图独立选择坐标字段；拖动子图标题到另一个同维度子图会把两组轨迹合并绘制，二维和三维之间不能合并。空间子图维护本次会话的完整轨迹历史，即使实时信号缓存滚动、暂停、切换页签或调整边界/视角也不会丢点；开始新采集或重新打开数据会清空历史。为控制绘制开销，每条轨迹最多向画布提交 4,000 个抽稀点。

每次采集在选定目录生成一对同名日志：`.bin` 保存串口送达应用的原始字节，`.csv` 保存成功解码的帧，每行有 UTC `Z` 时间戳与字段值。图表每个信号最多保留最近 30,000 个样本；更早数据可通过原始 `.bin` 日志回放。当前按单个选定模板采集，固定帧头和固定总帧长为基本规则，可选低 8 位累加和校验；尚未实现其他 CRC 算法。

如果画布只有坐标轴而没有曲线，先看“最近帧”是否新增行。若 `.bin` 有内容而 `.csv` 只有表头，说明收到原始字节但没有成功解析帧；界面也会提示收到的字节数。此时检查端口、串口参数、接线，以及数据是否符合模板的帧头、长度和校验规则。

CP01-B3 备惯导导航输出可加载 [专用模板](../samples/cp01_b3_navigation.json)，连接参数、合成测试帧和协议待确认项见 [CP01-B3 模板说明](CP01-B3导航模板说明.md)。该模板启用低 8 位累加和校验，并将状态、告警和故障位段作为独立数值信号；未配置校验的其他模板仍只按固定帧头和总帧长判断。

需要拆出单字节或无符号整数中的某些位时，在对应 `signals[]` 项同时设置 `bit_offset` 和 `bit_width`。位 0 是解码后整数的最低有效位，子信号按所选位段的自然数显示；不设置这两个字段时显示完整原始字段。CP01-B3 模板同时保留完整状态字和独立位段，选中位段子信号即可查看各位的 0/1 值。适配其他协议时参照 [协议模板 JSON 编辑指南](协议模板JSON编辑指南.md)。

## 验证状态

自动测试覆盖旧固定记录格式、大小端、跨块分帧、十六进制文本、帧导出、双日志、伪终端串口采集及 230400 波特率设计负载对应的 1 小时模拟字节量（18 MB、18 万帧）。CP01-B3 模板另有字段与分辨率逐项核对、合成帧解码、错误校验丢弃和伪终端实时采集测试。真实串口设备、目标 macOS 机器的连续运行和应用签名/公证仍需验收；当前安装包使用开发用途的临时签名。
