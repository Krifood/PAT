# CP01-B3 备惯导导航输出模板

协议来源：[备惯导发送数据表](备惯导发送数据表-CP01-B3导航输出协议.xlsx)的“表1 导航输出协议”和“说明”工作表。可直接加载的模板是 [cp01_b3_navigation.json](../samples/cp01_b3_navigation.json)。[cp01_b3_synthetic.hex](../samples/cp01_b3_synthetic.hex) 是按表格构造的测试帧，**不是设备抓包**。

## 串口试用

1. 使用与设备电平匹配的 RS-422 转接器。在 PAT 中选择“文件 → 打开格式”，加载上述 JSON 模板。
2. 在“串口采集”面板刷新并选择转接器端口，设置 **230400 bps、8 数据位、无奇偶校验、1 停止位、无流控**，然后点击“开始采集”。协议注明发送频率为 100 Hz。
3. 有效帧会进入“最近帧”表格和信号树；默认勾选滚转角、俯仰角、偏航角、组合海拔高度。其他字段可在信号树中勾选。原始 `.bin` 和成功解析 `.csv` 保存在面板指定的日志目录。

连接设备前，可先打开合成 `.hex` 文件验证离线显示：滚转角为 `-12.34°`，俯仰角为 `2.5°`，偏航角为 `90°`，组合海拔高度为 `123.45 m`；系统状态 2 的导航状态码为 `5`、定位状态码为 `4`。该帧的校验字节是 `B7`。

## 模板映射

| 协议位置（从 1 计数） | 模板规则 |
| --- | --- |
| 第 1–4 字节 | 固定 `EB 90 1A 56`：帧头、帧号和总长度；用于识别该导航输出帧 |
| 第 1–86 字节 | 固定总帧长 86 字节；字段偏移在 JSON 中从 0 计数 |
| 多字节字段 | 小端；按表格的有符号/无符号类型、分辨率和单位解码 |
| 第 86 字节 | 第 3–85 字节累加和的低 8 位；校验失败的候选帧不进入曲线或成功解析日志，原始字节仍保留在 `.bin` |

模板覆盖除固定 2 字节帧头外的全部 40 个原始字段，包括帧号、长度、状态、诊断、导航数值、帧计数和校验字节。另从状态字派生 42 个位段信号，共 82 个可选信号；原始字段也保留，便于核对。信号列表将四个常用曲线字段放在最前面；每个字段的 `byte_offset` 仍严格按协议位置填写。模板 ID 已升为 `cp01_b3_navigation_output_v2`，成功解析 CSV 因新增位段信号而增加列。

## 已确认处理规则

- 未注明分辨率的字段按 `1` 处理。“GPS 周秒”按每计数 `1` 显示；模板根据字段名称标注单位 `s`，实际时间基准仍需用设备样本核对。
- 系统状态 1 的 8 个单比特位、系统状态 2 的高/低半字节、告警字与故障字的已定义 16 个位，分别提取并按十进制自然数显示。单比特位为 `0` 或 `1`，状态码按原值显示；位编号从解码后无符号整数的最低有效位 0 开始。
- 三项“过载”的单位按设备回复修正为 `m/s²`，分辨率仍为 `1e-2`。

## 仍待设备数据确认

- 数据源 ID 的枚举值、告警与故障触发条件、系统状态 2 高半字节值 `3` 的含义仍未给出；模板保留原始整数与逐位数值，不代填含义。
- 当前累加和范围依据“**不算帧头和校验字节**”解释为第 3–85 字节。真实设备样本到位后，应核对校验范围、字段数值和 100 Hz 连续采集结果。
