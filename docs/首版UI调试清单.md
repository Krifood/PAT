用仓库合成样本执行 macOS Qt offscreen 截图检查，覆盖 1100×720 和 1366×768：空界面、时序三子图、二维轨迹。

### 2026-10-27：数据读数真实性与主题提示

- 排查结论：原始时序没有做平滑/均值，抽稀选择已有极值样本；但原游标及垂向辅助线会对相邻样本线性插值，产生非日志采样值。现改查最近已加载的数据点，`k:` 为该点实际时间；数据覆盖外和缺失段不出读数。
- 派生图显式配置的线性插值/前值保持继续保留，不更改用户选择的运算。横向辅助线的交点属于连线几何计算，已明确标注；鼠标屏幕映射坐标也标注“非采样”。直线连接仍仅用于绘图，不等于新增采样数据。
- 数据提示使用统一主题文字/背景，浅色及户外主题不再固定黑底黄字；主游标 9pt 常规字重，色条缩至 1px 并降低不透明度，QLabel 提示采用淡边框。包括极值、辅助线提示及二维/三维时间/位置提示。
- 新增 `cursorReadsSamplesWithoutInterpolation` 与 `readoutsFollowAllThemes`：验证突变点不插值、不外推、不跨缺失段，保留明确的阶梯保持结果；验证三主题配色、对比度、字号、实际绘制背景色及所有相关提示样式。
- 本轮完整回归通过：core 25 通过/2 个可选跳过、serial 5 通过、UI 40 通过；`git diff --check` 通过。
