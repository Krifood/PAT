# 0.1.4 布局与二维测距

日期：2026-11-10（Asia/Shanghai）。本轮是开发检查点，不是跨平台验收发布。

## 需求与使用

1. 信号区边缘的 ◀ / ▶ 收起或展开整个侧栏，保留当前勾选、搜索、分组与数据；收起后空间让给绘图区。
2. 每个时序子图右上角 × 关闭本图全部信号，同步信号选择状态。二维/三维沿用右上角 ×；关闭空间子图会清除该子图会话轨迹，但不会删除源文件。
3. 精简按钮及菜单中的括号解释、重复操作说明。操作细节保留在工具提示和文档；数据单位、非采样标记、故障警告不隐藏。
4. 空间视图新增“新增地理子图”。地理子图仍是二维信号坐标图，不是地图底图；X 选择经度，Y 选择纬度。坐标模式明确选择“经纬度 · 度”或“经纬度 · 弧度”，不猜测单位。普通二维图可选择“平面坐标”。
5. 勾选“测距”：靠近轨迹真实采样点（18 个逻辑像素内）单击设置起点，移动鼠标预览距离；靠近另一采样点单击锁定终点。再次单击采样点开始新测量。右键清除锚点但保持测距开启，可立即重选；取消勾选退出测距，恢复框选缩放与普通右键菜单。
6. 查看 → 显示主题 → 柔和深绿，选择会持久化到应用设置。

## 测距语义与边界

- 吸附候选使用当前可见时间区间、可见轨迹的完整已加载配对样本，不使用绘图抽稀后的点或线段插值。没有吸附的预览端点标记“指针”，不能点击成为锚点；吸附端点标记“采样点”。
- 测量使用当前显示坐标（包含用户显式设置的比例/平移）。地理模式必须保证变换后的 X/Y 分别是正确的经度/纬度；平面模式两轴必须同单位，距离显示“坐标单位”，不擅自标米。
- 地理距离是两点的球面最短地表距离（Haversine，平均半径 6371008.8 m），不是沿轨迹累积里程，不包含高度，不是 WGS84 椭球高精度测量。纬度限定 ±90°、经度限定 ±180°，弧度模式对应 ±π/2、±π；越界提示检查坐标与单位。跨 ±180° 使用最短球面距离，但图上连线仍遵循原始经纬坐标布局。
- 原始日志、采样值和缓存格式不变。测距为会话交互，不保存到数据文件。重绘数据、更改区间、信号、显示变换或模式后清除锚点，避免旧锚点误导。实时持续刷新时建议暂停显示再测量。
- 只支持二维，包括地理模式；三维不提供地表测距。不同轨迹间可测量，需由用户确认坐标系与单位一致。
